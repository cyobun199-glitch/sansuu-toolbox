# さんすう・生活アシスト ツールボックス

小学生の学習と毎日の生活を支援する、ブラウザだけで動く個人開発の試作品です。

## 収録ツール

| ファイル | 内容 |
| --- | --- |
| `index.html` | 数をブロックや筆算で視覚化する「さんすう みてわかるツール」 |
| `ondoku.html` | 音読練習を支援するツール |
| `challenge.html` | 生活タスク、学習クイズ、料理の安全クイズを冒険にした「がんばりチャレンジ！」 |

サーバーやインストールは不要です。使いたい HTML ファイルをブラウザで開くと試せます。入力したタスクや達成状況は、基本的に利用中のブラウザ内へ保存されます。

## ゲームとして公開・販売するには

このリポジトリの `challenge.html` は、まず家族で試すための小さなブラウザゲーム（プロトタイプ）として利用できます。商品化する場合は、次の順番がおすすめです。

生活タスクを終えると「元気」がたまり、まなびダンジョンの計算・言葉・料理クイズで正解すると装備を獲得できます。問題文の読み上げと、キャラクターが障害物を飛び越える演出も試せます。データはブラウザ内に保存されます。

1. 家族だけで使い、分かりにくい操作や続けにくい点を記録する。
2. タスク、報酬、演出を少しずつ改善する。
3. GitHub Pages などで限定的にテスト公開する。
4. itch.io で無料版または低価格版を公開し、利用者の反応を確認する。
5. 必要になった段階で、Steam やアプリストア向けのパッケージ化を検討する。

### 制作方法の選び方

| 方法 | 向いているケース | 特徴 |
| --- | --- | --- |
| この HTML を Codex と育てる | 今ある試作品を早く改善したい | ブラウザで動き、画面・保存・ゲーム機能を自由に追加できる |
| [GDevelop](https://gdevelop.io/game-makers) | ノーコード中心で2Dゲームを作りたい | イベントを組み合わせて制作し、Web・PC・モバイル向けに書き出せる |
| [RPGツクールMZ](https://www.rpgmakerweb.com/products/rpg-maker-mz) | 会話や物語中心のRPGを作りたい | マップ、会話、戦闘などの仕組みがあらかじめ用意されている |
| [Construct 3](https://www.construct.net/en) | ブラウザで2Dゲームを作りたい | ビジュアルなイベント方式で、Web公開と相性がよい |
| [Godot](https://godotengine.org/) | コードも使って本格的に拡張したい | 無料・オープンソースで、2D・3Dの両方に対応する |

### 公開・販売先

- **[itch.io](https://itch.io/docs/creators/faq)** — ブラウザゲームの初回公開やテスト販売に向いています。無料配布、固定価格、任意支払いを選べます。
- **[Steam](https://partner.steamgames.com/doc/gettingstarted/appfee)** — 完成度を高めて世界向けに販売したい場合の候補です。作品ごとの登録料やストア素材、審査準備が必要です。
- **自分の販売ページ** — 紹介ページは自作できますが、カード情報を自分で保管せず、[Stripe Payment Links](https://docs.stripe.com/payment-links) などの決済サービスを利用する方が安全です。

Codexは、ゲーム画面、ポイント・レベル、保護者用設定、データ保存、テストなどの実装を支援できます。ただし、Codexそのものは販売サイトや決済サービスではありません。制作したゲームを上記の公開先へ登録します。

## 商品化前のチェックリスト

- 画像、音楽、効果音、フォントの商用利用条件とクレジット表記を確認する。
- 子どもの氏名、写真、行動履歴など、不要な個人情報を収集しない設計にする。
- データの保存場所、削除方法、問い合わせ先を利用者へ明示する。
- 決済、返金、税金、各ストアの年齢区分・子ども向け規則を、公開時点の公式情報で確認する。
- 最初から大規模にせず、「家族用 → 少人数テスト → 無料版 → 有料版」の順で検証する。

> 料金、手数料、公開条件は変更されることがあります。販売を始める前に、各サービスの公式ページで最新情報を確認してください。
